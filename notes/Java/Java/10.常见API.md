## 2.2 创建String对象的方式

1. **直接赋值**

![image-20260408211809001](10.常见API/image-20260408211809001.png)

2. **new关键字**

![image-20260408211859256](10.常见API/image-20260408211859256.png)

````java
package com.itbbben.apiString.Test2;

public class Test {
    public static void main(String[] args) {
        String s = "abc";
        System.out.println(s);

        // new+构造方法的方式创建字符串对象
        // new + 空参构造
        String s1 = new String();
        System.out.println("--" + s1 + "￥￥");

        // new + 带参数的构造方法
        String s2 = new String(s);
        System.out.println(s2);

        // new + 有参构造（字符数组）
        char[] chas = {'a', 'b', 'c', 'd'};
        String s3 = new String(chas);
        System.out.println(s3);

        // new + 有参构造（字节数组）
        // ASCII码表对应的字符
        byte[] bytes = {97, 98, 99, 100};
        String s4 = new String(bytes);
        System.out.println(s4);
    }
}
````

#### 2.3.1.1 字符串比较

- `boolean equalsIgnoreCase(要比较的字符串)` 忽略大小写的比较

### 2.3.2 遍历字符串

- `public char charAt(int index)`：根据索引返回字符（索引从左到右从0开始）
- `public int length()`：返回此字符串的长度
  - 数组的长度：`数组名.length`这里不需要加括号，length是数组的一个属性，而字符串这里是方法需要加括号
  - 字符串的长度：`字符串对象.length`

### 2.3.3 数据脱敏（字符串截取）

- 数据脱敏是一种有效的**数据保护手段**，能够**降低数据泄露的风险**，保护用户隐私

- `String substring(int beginindex, int endindex)`：截取索引从beginindex到endindex-1

- `String substring(int beginindex)`：索引从beginindex截取到末尾

## 3.2 ArrayList构造方法

![image-20260605173339647](10.常见API/image-20260605173339647.png)

![image-20260605173408961](10.常见API/image-20260605173408961.png)

- **如果没有进行限定，集合里面可以存储任意数据类型的数据**
- **泛型**：限定集合当中的数据类型 `<数据类型>`

```java
ArrayList<String> list = new ArrayList<String>();

// jdk7之后，后面的泛型可以省略不写，但是尖括号必须保留
ArrayList<String> list = new ArrayList<>();
```

### 3.2.1 添加数据

`list.add('aaa')`

`list.add(0, 'bbb')`

**ArrayList的add方法不管添加什么都添加成功，忽略返回值即可**

- true：添加成功   falase：添加失败
- add方法在任意情况下，都会添加成功，永远不会失败
- 在JAVA当中，存在很多很多集合 比如HashSet(元素要唯一) aaa(true) aaa(false)
- 设计：跟其他的思想保持统一（面向对象的思想）

![image-20260605180733314](10.常见API/image-20260605180733314.png)

```java
// 直接添加
public class Test {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        boolean a = list.add("aaa");

        System.out.println(a);
        System.out.println(list);
    }
}
true
[aaa]
    
// 添加到指定索引的地方
public class Test {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        list.add("aaa");
        list.add(0, "bbb");
        System.out.println(list);
    }
}
[bbb, aaa]
```

**在集合当中无法直接添加基本数据类型（byte short int long float double char boolean）**

**只能添加引用数据类型（对象）**

**如果在集合里面一定要添加基本数据类型，那么可以转成其对应的包装类**

### 3.2.2 删除元素

`list.remove("aaa")`：根据元素的内容进行删除，存在则删除成功，不存在则删除失败

`list.remove(0)`：根据索引进行删除的，会把被删除的元素进行返回，如果当前的索引不存在则报错

```java
// 删除指定元素
public class Test {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        list.add("aaa");
        list.add(0, "bbb");

        boolean res = list.remove("aaa");
        System.out.println(res);
        System.out.println(list);
    }
}
true
[bbb]
    
// 根据索引删除并返回指定元素
public class Test {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();
        

        String res = list.remove(0);
        System.out.println(list);
    }
}
[aaa]
```

### 3.2.3 修改元素

`list.set(0, "bbb")`：将指定索引的数据修改成指定数据，把被替换的元素进行返回，如果当前的索引不存在则会报错

```java
public class Test {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        list.add("aaa");
        System.out.println(list);
        String res = list.set(0, "bbb");
        System.out.println(res);
        System.out.println(list);
    }
}
[aaa]
aaa
[bbb]
```

### 3.2.4 获取元素

`list.get(0)`：获取指定索引的元素

`list.size()`：获取集合长度

```java
public class Test {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        list.add("aaa");
        String res = list.get(0);
        System.out.println(res);
        System.out.println(list);
    }
}
aaa
[aaa]
```

- 遍历获取元素

```java
public class Test {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        list.add("aaa");
        list.add("bbb");
        for (int i = 0; i < list.size(); i++) {
            String s = list.get(i);
            System.out.println(s);
        }
        System.out.println(list);
    }
}
```
