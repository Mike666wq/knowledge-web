# 代码执行漏洞完全指南

## 1. 什么是代码执行漏洞

代码执行漏洞是指用户的输入被当作后端代码直接执行，通常是因为使用了危险的函数。攻击者可以通过构造恶意输入，在服务器上执行任意PHP代码。

### 1.1 危害

- 执行任意PHP代码
- 读取服务器敏感文件
- 获取服务器控制权
- 进行横向移动

-------------------------------

代码执行是执行PHP代码。命令执行是执行linux系统下的命令。 这两者是有区别的。有些代码在php下看起来是有错的，但是在linux下是正确的。 一些工具

## 2. 危险函数详解

### 2.1 eval函数

- `eval()`函数可以直接执行PHP代码
- 需要以`;`符号结尾

```php
<?php
eval($_POST['cmd']);
?>
```

**利用方式**：POST提交`cmd=phpinfo();`或`cmd=system('whoami');`

### 2.2 assert函数

- `assert()`断言函数，用于判断一段代码执行结果是真还是假
- 在PHP 7.x中已废弃，PHP 8.x中已移除

```php
<?php
assert($_POST['cmd']);
?>
```

### 2.3 call_user_func函数

- 可以调用指定的函数

```php
<?php
// call_user_func('system','ls')
call_user_func('eval',$_POST['cmd']);
?>
```

**利用方式**：POST提交`cmd=system('whoami');`

### 2.4 create_function函数

- 动态创建函数并执行

```php
<?php
$a = $_POST['func'];
$b = create_function('$a',"echo $a");
$b('');
?>
```

**利用方式**：POST提交`func=system('whoami');}function test(){//`

### 2.5 array_map函数

- 依次将数组中的元素取出，带入到指定函数执行

```php
<?php
$array = array(0,1,2,3,4,5);
array_map($_POST['func'],$array);
?>
```

**利用方式**：POST提交`func=system&array[]=whoami`

### 2.6 其他代码执行函数

- `preg_replace()`：当使用`/e`修饰符时，替换字符串会被当作PHP代码执行（PHP 5.x中可用）
- `call_user_func_array()`：调用回调函数，并把一个数组参数作为回调函数的参数
- `array_walk()`：对数组中的每个元素应用回调函数
- `usort()`：使用用户自定义的比较函数对数组中的元素进行排序

---

## 3. 漏洞防御

1. **禁用危险函数**：在`php.ini`中禁用`eval()`、`assert()`等函数
2. **输入验证**：严格验证用户输入
3. **使用安全函数**：避免使用`eval()`等危险函数
4. **代码审计**：定期进行代码安全审计

## 4. 速查表

### 4.1 代码执行函数速查

| 函数 | 说明 | 危险程度 |
|------|------|---------|
| eval() | 执行PHP代码 | 极高 |
| assert() | 断言并执行代码（PHP 7.x已废弃） | 高 |
| call_user_func() | 调用回调函数 | 高 |
| create_function() | 动态创建函数 | 高 |
| array_map() | 对数组元素应用函数 | 中 |
| preg_replace() | 正则替换（/e修饰符） | 高 |
