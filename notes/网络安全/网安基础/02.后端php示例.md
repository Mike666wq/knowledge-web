## 1.1 $_REQUEST数组接收前端数据

- php中`$_REQUEST`是全局变量，用来接收用户输入
  - 当网页跳转到此页面的时候，会把用户输入的数据传输给`$_REQUEST`
  - `$_REQUEST`是一个数组，包含了用户输入的所有数据
  - php的数组都是key,value的形式，["name":"张三", "age":"18"]
  - 注意：打印字符串可以使用`echo`，但是打印数组必须使用`print_r`

```php
<?php
$res = $_REQUEST;
print_r($res);
?>
```

- 此时在前端页面提交的数据就可以在这个数组里面得到

![image-20260422192452920](02.后端php示例/image-20260422192452920.png)

--------------

- 此时就可以基础这个数组使用最简单的if语句判断账号密码是否正确，当然上面使用的是`GET`提交的，地址栏就可以直接看到，很不方便，下面前端使用`POST`提交

- `GET`方式提交那些需要用书签存储下来的，**所有的信息都在网址中**；而`POST`方式用于提交用户密码这些不需要存储下来的，**所有的信息都在请求体中**

  - 后端php里面的`$_REQUEST` 默认包含 `$_GET` + `$_POST` + `$_COOKIE` 的数据。所以无论表单用 GET 还是 POST，`$_REQUEST` 都能拿到值。但**不推荐**用 `$_REQUEST`，因为：

    - 存在变量覆盖的安全风险（COOKIE 同名字段会覆盖 GET/POST）

    - 无法明确数据来源，不利于排查问题

  - 所以后端最好也使用`$_POST`数组来读取数据

```php
<?php
header("Content-Type: text/html; charset=utf-8");
$username = $_POST['username'];
$password = $_POST['password'];

if ($username == "user01" && $password == "11111") {
    echo "登录成功";
} else {
    echo "登录失败";
}
?>
```

## 2.3 进入mysql数据库并插入一条新数据（注册逻辑）

- 此时再写一个`register.html`登录界面，修改`login.html`对应代码并且将注册的后端处理逻辑与登录放到一起，所以将上面的`login.php`改为`users.php`

- 此时在`users.php`中就需要明确区分登录的逻辑以及注册的逻辑
  - 不管是**登录逻辑**还是**注册逻辑**都需要**连接数据库**
  - 只有**登录逻辑**需要**从前端获取用户名和密码**
  - 用来**区分前端给后端的数据中是注册逻辑还是登录逻辑的关键点**在前端代码中**最后的登录或者注册`submit`按钮的的`name`**(注意：**前端提交的就是带有name标签的数据**)

-----------

- 注册逻辑：
  - 先从前端获取用户名，以及两次密码输入，邮箱
  - 插入新的用户记录之前先要检查两次密码是否相同以及用户名或邮箱是否已经存在
  - 然后写sql语句，插入一条新的用户记录。插入成功后，返回注册成功信息

```php
<?php
// 处理用户登录和注册相关的代码
// 设置页面编码为utf-8
header("Content-Type: text/html; charset=utf-8");

// 连接mysql数据库
$host = "127.0.0.1";
$user = "root";
$userpassword = "usbw";
$database = "blog";
$port = "3307";
$conn = mysqli_connect($host, $user, $userpassword, $database, $port);
if (!$conn) {
    die("连接失败: " . mysqli_connect_error());
    exit;
}   

// 先判断$_REQUEST中是否存在'login'或者'register'参数，如果存在，则执行对应的操作，否则返回错误信息
if(isset($_REQUEST['login'])) {
    // 从前端获取用户名和密码
    $username = $_POST['username'];
    $password = $_POST['password'];

    // 查询数据库中的user表，并且将$username和$passwrod作为条件查询
    $sql = "select * from users where username='$username' and password='$password'";
    $result = mysqli_query($conn, $sql);

    if (!$result) {
        echo "查询失败: " . mysqli_error($conn);
        exit;
    }

    // 如果查询结果为空，提示用户名或密码错误
    if (mysqli_num_rows($result) == 0) {
        echo "用户名或密码错误 <a href='login.html'>返回登录页面</a>";
        exit;
    } else {
        echo "登录成功";
    }
} elseif(isset($_REQUEST['register'])) {
    // 先从前端获取用户名，以及两次密码输入，邮箱或手机号
    $username = $_POST['username'];
    $password = $_POST['password'];
    $confirm_password = $_POST['confirm_password'];
    $email = $_POST['email'];

    // 判断两次密码输入是否一致
    if($password != $confirm_password) {
        echo "两次密码输入不一致";
        exit;
    }

    // 判断用户名或邮箱是否存在
    $sql = "select * from users where username='$username' or email='$email'";
    $result = mysqli_query($conn, $sql);

    if (mysqli_num_rows($result) > 0) {
        echo "用户名或邮箱已存在";
        exit;
    }

    // 然后写sql语句，插入一条新的用户记录
    $sql = "insert into users (username, password, email) values ('$username', '$password', '$email')";
    $result = mysqli_query($conn, $sql);

    // 插入成功后，返回注册成功信息
    if($result) {
        echo "注册成功";
    } else {
        echo "注册失败: " . mysqli_error($conn);
    }
} else {
    echo "错误：未知操作";
    exit;
}
?>
```

        }
    } else {
        // 更新用户名和邮箱，不修改密码
        $sql = "update users set username='$username', email='$email' where id='$userid'";
        $result = mysqli_query($conn, $sql);

# 5. 博客前台实现

- 新建一个`index.php`文件，访问8080端口时直接访问
- 前台主要就是展示所有的文章内容，后续还可以点进具体的文章页面`article.php`查看以及文章评论的功能
- 最基础前台功能

```php
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>bbben的小站</title>
</head>

<body>
    <h1>bbben的小站</h1>
    <ul>
        <?php
        include("db.php");
        $sql = "select * from articles";
        $result = mysqli_query($conn, $sql);
        while ($row = mysqli_fetch_assoc($result)) {
        ?>
            <li onclick="location.href='article.php?id=<?php echo $row['id']; ?>'">
                <p><?php echo $row['title']; ?></p>
                <p><?php echo $row['author']; ?></p>
                <p><?php echo $row['time']; ?></p>
            </li>
        <?php
        }
        ?>
    </ul>
</body>

</html>
```

- `article.php`展示具体文章内容，根据传过来的`id值`进行查询

```php
<!DOCTYPE html>
<html lang="en">
<head>
    <?php
    include("db.php");
    $id = $_GET['id'];
    $sql = "select * from articles where id='$id'";
    $result = mysqli_query($conn, $sql);
    $row = mysqli_fetch_assoc($result);
    ?>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>bbben的小站 - <?php echo $row['title']; ?></title>
</head>
<body>
    <h1><?php echo $row['title']; ?></h1>
    <h3><?php echo $row['author']." - ".$row['time']; ?></h3>
    <p><?php echo $row['content']; ?></p>
    <a href="/">返回首页</a>
</body>
</html>
```
