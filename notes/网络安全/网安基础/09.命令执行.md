# 命令执行漏洞完全指南

## 1. 什么是命令执行漏洞

命令执行漏洞是指用户的输入被当作系统命令直接在操作系统上执行，通常比代码执行漏洞危害更大。

### 1.1 危害

- 执行任意系统命令
- 获取服务器控制权
- 读取敏感文件
- 进行横向移动
- 完全控制服务器

---

## 2. 危险函数详解

### 2.1 system函数

- 直接在系统的命令行执行命令
- 命令执行结果会直接输出

```php
<?php
system('ls');
?>
```

### 2.2 passthru函数

- 直接执行系统命令
- 与system类似，但不会捕获输出

```php
<?php
passthru("whoami");
?>
```

### 2.3 exec函数

- 执行系统命令，但不会直接显示执行结果
- 需要使用`echo`或`print`输出结果
- 返回命令执行结果的最后一行

```php
<?php
echo exec("touch file{1..9}");
?>
```

### 2.4 pcntl_exec函数

- 在当前进程空间执行指定程序
- 需要安装pcntl扩展

```php
<?php
pcntl_exec("/bin/bash", array("whoami"));
?>
```

### 2.5 shell_exec函数

- 通过shell执行命令
- 将完整的输出以字符串的方式返回

```php
<?php
echo shell_exec("whoami");
?>
```

### 2.6 popen函数

- 打开进程文件指针
- 可以读取或写入命令的输出

```php
<?php
popen('whoami', 'w');
?>
```

### 2.7 反引号执行

- 在PHP中，反引号`` ` ``等同于`shell_exec()`

```php
<?php
echo `whoami`;
?>
```

### 2.8 其他命令执行函数

- `exec()`：执行命令并返回最后一行结果
- `system()`：执行命令并直接输出结果
- `passthru()`：执行命令并直接输出二进制结果
- `shell_exec()`：通过shell执行命令并返回完整输出
- `popen()`：打开进程文件指针
- `proc_open()`：打开进程文件指针，返回文件指针数组
- `pcntl_exec()`：在当前进程空间执行指定程序

---

## 3. 漏洞防御

1. **禁用危险函数**：在`php.ini`中禁用`system()`、`exec()`、`shell_exec()`等函数
2. **输入过滤**：过滤`|`、`;`、`&`、`&&`、`||`等命令连接符
3. **使用参数化**：避免将用户输入直接拼接到命令中
4. **最小权限**：Web服务器使用最小权限运行
5. **使用安全函数**：使用`escapeshellarg()`和`escapeshellcmd()`转义参数

---

## 4. 速查表

### 4.1 命令执行函数速查

| 函数 | 输出 | 返回值 | 说明 |
|------|------|--------|------|
| system() | 直接输出 | 命令执行状态 | 执行命令并输出结果 |
| exec() | 不输出 | 最后一行结果 | 需要echo输出 |
| shell_exec() | 不输出 | 完整输出 | 通过shell执行 |
| passthru() | 直接输出 | 无 | 执行命令并输出二进制 |
| popen() | 不输出 | 文件指针 | 打开进程文件指针 |
| pcntl_exec() | 不输出 | 无 | 在当前进程执行 |
