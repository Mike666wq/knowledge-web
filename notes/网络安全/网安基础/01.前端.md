# 1. HTML（HyperText Markup Language）

> **作用**：定义网页的**结构与语义**，是页面的骨架。

## 1.1 HTML 基本结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>页面标题</title>
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
```

**关键点记忆：**

- `<!DOCTYPE html>`：声明 HTML5 文档
- `<html lang="zh-CN">`：语言声明，利于 SEO 和无障碍
- `<meta charset="UTF-8">`：防止中文乱码
- `<head>`：放元数据、样式、脚本引用
- `<body>`：可见页面内容

-------------

## 1.2 常用标签分类

### （1）文本与排版

| 标签          | 含义             |
| ------------- | ---------------- |
| `<h1> ~ <h6>` | 标题             |
| `<p>`         | 段落             |
| `<br>`        | 换行             |
| `<hr>`        | 水平分割线       |
| `<strong>`    | 加粗（语义强调） |
| `<em>`        | 斜体（语义强调） |

-------------------

### (2) 列表

```html
<ul>
  <li>无序列表</li>
</ul>

<ol>
  <li>有序列表</li>
</ol>

<dl>
  <dt>名词</dt>
  <dd>解释</dd>
</dl>
```

-----------------

### (3) 超链接与图片

```html
<a href="https://example.com" target="_blank">跳转</a>
<img src="img.png" alt="描述文字">
```

**注意点：**

- `alt`属性对 SEO 和无障碍非常重要
- `target="_blank"`会打开新窗口

-----------

### （4）表单

```html
<form action="/submit" method="post">
  <label for="user">用户名：</label>
  <input type="text" id="user" name="username" required>

  <label for="pwd">密码：</label>
  <input type="password" id="pwd" name="password">

  <input type="submit" value="提交">
</form>
```

常见 input 类型：

- `text / password`
- `email / number`
- `checkbox / radio`
- `file`
- `hidden`

-------------

### （5）语义化标签（HTML5）

```html
<header>头部</header>
<nav>导航</nav>
<main>主要内容</main>
<section>区块</section>
<article>独立内容</article>
<footer>页脚</footer>
```

### （6）表格

表格是一个二维数据空间，一个表格由若干行组成，一个行又有若干单元格组成，单元格里可以包含文字、列表、图案、表单、数字符号、预置文本和其它的表格等内容。 表格最重要的目的是显示表格类数据。表格类数据是指最适合组织为表格格式（即按行和列组织）的数据。 表格的基本结构：

```html
<table>
  <thead>
    <tr>
      <th>姓名</th>
      <th>性别</th>
      <th>爱好</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>张三</td>
      <td>男</td>
      <td>男</td>
    </tr>
    <tr>
      <td>李四</td>
      <td>男</td>
      <td>女</td>
    </tr>
  </tbody>
</table>
```

属性: border: 表格边框. cellpadding: 内边距 cellspacing: 外边距. width: 像素 百分比.（最好通过css来设置长宽） rowspan: 单元格竖跨多少行 colspan: 单元格横跨多少列（即合并单元格）

✅ **学习重点**：

- 用语义标签代替大量 `<div>`
- 提升可读性和 SEO

# 2.CSS（Cascading Style Sheets）

> **作用**：控制网页的**表现与布局**，是页面的皮肤。

-------------

## 2.1 CSS 引入方式

```html
<!-- 行内样式（不推荐） -->
<div style="color:red;"></div>

<!-- 内部样式 -->
<style>
  p { color: blue; }
</style>

<!-- 外部样式（推荐） -->
<link rel="stylesheet" href="style.css">
```

--------------

## 2.2. 选择器（重点）

| 类型         | 示例               |
| ------------ | ------------------ |
| 元素选择器   | `p {}`             |
| class 选择器 | `.box {}`          |
| id 选择器    | `#main {}`         |
| 后代选择器   | `ul li {}`         |
| 伪类         | `a:hover {}`       |
| 伪元素       | `p::first-line {}` |

✅ **优先级记忆口诀**：

```html
!important > 行内 > ID > Class > 元素
```

---------

## 2.3 盒模型（必考核心）

```html
margin → border → padding → content
.box {
  width: 200px;
  padding: 10px;
  border: 2px solid #000;
  margin: 20px;
}
```

⚠️ 注意：

- `box-sizing: border-box;`让 width 包含 padding 和 border（推荐）

## 2.4 常用样式属性

### 文本样式

```html
p {
  color: #333;
  font-size: 16px;
  line-height: 1.5;
  text-align: center;
}
```

### 背景

```html
body {
  background-color: #f5f5f5;
  background-image: url(bg.png);
  background-repeat: no-repeat;
}
```

-------

## 2.5 布局方式（重点）

### （1）标准流（文档流）

- 块级元素：独占一行
- 行内元素：同行排列

### （2）浮动布局（传统）

```html
.left { float: left; }
.right { float: right; }
.clear { clear: both; }
```

⚠️ 需要清除浮动

-----------

### （3）Flex 布局（强烈推荐掌握）

```html
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

常用属性：

- `flex-direction`
- `justify-content`
- `align-items`
- `flex-wrap`

-----------

### （4）Grid 布局（进阶）

```html
.container {
  display: grid;
  grid-template-columns: 200px 1fr;
}
```

-----------

## 2.6 定位（Position）

| 值       | 说明               |
| -------- | ------------------ |
| static   | 默认               |
| relative | 相对自身           |
| absolute | 相对最近定位父元素 |
| fixed    | 固定窗口           |
| sticky   | 吸顶效果           |

```html
.box {
  position: absolute;
  top: 10px;
  left: 20px;
}
```
