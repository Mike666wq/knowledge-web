# 跨域资源共享CORS

- 跨域资源共享(CORS)是一种`浏览器安全机制`，用于允许在一个源(Origin)的Web应用，通过浏览器向另一个源的服务器发起跨域HTTP请求，并在`服务器授权`的前提下获取资源

## 同源的`三个条件`：

- 协议
- 域名
- 端口
