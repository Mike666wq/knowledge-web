# 1. 参数

![img](04.参数/1768400680079-61.png)

- 参数就是客户端发送请求时附带的`额外信息和指令`
- 参数的作用是让`同一个接口`能`根据不同的输入`，`返回不同的输出`，实现`动态交互`

## 1.2 参数分类

- 参数可分为：路径参数、查询参数、请求体

## 类型注解Path，（范围限制路径参数）

- FastAPI允许为参数声明`额外`的信息和校验
- 需要先导入FastAPI的`Path`函数

![img](04.参数/1768400680075-51.png)

- 具体写法

```Python
from fastapi import FastAPI, Path    # 导入Path函数

@app.get("/book/{id}")
async def get_book(id: int = Path(..., gt=0, lt=101, description="书籍id，取值范围1~100")):
    return {"id": id, "title": f"这是第{id}本书"}
```

# 3. 查询参数

- 位置：URL`?之后k1=v1&k2=v2`
- 作用：对资源集合进行过滤、排序、分页等操作
- 方法：`GET`
- 声明的参数`不是路径参数`时，路径操作函数会把该参数`自动解释为查询参数`

![image-20260114224433296](04.参数/image-20260114224433296.png)

- 代码实现

```python
# 需求 查询新闻 → 分页，skip:跳过的记录数，limit:返回的记录数 10
@app.get("/news/news_list")
async def get_news_list(skip: int, limit: int=10):
    return {"skip":skip, "limit":limit}
```

## 类型注解Query，（范围限制查询参数）

```python
from fastapi import FastAPI, Query		# 要导入Query函数

@app.get("/news/news_list")
async def get_news_list(
        skip: int = Query(0, description="跳过的记录数", lt=100),	# 这里的Query函数用法和上面的Path函数用法一样
        limit: int= Query(10, description="返回的记录数")
):
    return {"skip":skip, "limit":limit}
```

# 4. 请求体

- 位置：HTTP请求的`消息体（body）`中
- 作用：创建、更新资源，携带大量数据，如：JSON
- 方法：`POST`、`PUT`等
- 在HTTP协议中，一个完整的请求由三部分组成：
  - 请求行：包含方法(get，post等)、URL、协议版本
  - 请求头：元数据信息（Content-Type、Authorization等）
  - **请求头**:**实际要发送的数据内容**

## 4.6 请求体参数-类型注解Field

### 4.6.1 导入`pydantic`的`Field`函数

![image-20260115002247799](04.参数/image-20260115002247799.png)

- `Field`参数要求

![image-20260115002340242](04.参数/image-20260115002340242.png)

### 4.6.2 代码实现

```python
from pydantic import BaseModel, Field


class User(BaseModel):      # 这里User类继承BaseModel类
    username: str = Field(default="大黄", min_length=2, max_length=10, description="用户名，长度要求2-10个字")
    password: str = Field(min_length=3, max_length=20)

@app.post("/register")
async def register(user: User):
    return user
```
