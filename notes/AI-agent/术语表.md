# Agent 开发术语表

- **Agent**：围绕目标进行观察、决策、行动和反馈循环的软件系统。
- **LLM**：Large Language Model，大语言模型；负责语言理解、生成和一定程度的推理。
- **Token**：模型处理文本的基本单位，不等同于字符或单词。
- **Context Window**：一次请求可容纳的输入与输出 Token 总量上限。
- **Prompt**：发送给模型的指令、背景、示例和输出要求。
- **Message**：对话协议中的消息，常见角色有 system、user、assistant、tool。
- **Tool Calling**：模型生成结构化工具名称和参数，由应用执行实际函数。
- **ReAct**：Reason + Act，通过推理、行动、观察的循环解决任务的方法。
- **State**：工作流当前可读取和更新的数据集合。
- **Memory**：跨步骤或跨会话保留并在需要时取回的信息机制。
- **Checkpoint**：工作流状态的持久化快照，用于恢复、追踪或人工介入。
- **RAG**：Retrieval-Augmented Generation，先检索外部资料，再基于资料生成答案。
- **Embedding**：把内容映射为向量，以便计算语义相似度。
- **Vector Store**：保存向量及元数据、支持相似度检索的存储系统。
- **Chunk**：从文档切分出的检索单元。
- **Structured Output**：遵循 JSON 或数据模型等明确结构的模型输出。
- **Router**：根据状态或模型判断选择下一条路径的组件。
- **Planner**：把目标拆分为步骤或任务的组件。
- **Executor**：执行计划、工具或子任务的组件。
- **Reviewer/Critic**：检查结果是否满足标准并给出修订意见的组件。
- **Human-in-the-loop**：在关键步骤引入人工确认、修改或审批。
- **Observability**：通过日志、Trace、指标和事件理解系统实际运行过程的能力。
- **Evaluation**：用数据集和指标衡量正确性、检索效果、工具选择、安全和成本。
