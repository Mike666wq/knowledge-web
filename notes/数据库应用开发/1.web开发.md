# HTML

- 一种标记语言，不是编程语言，用于书写页面的内容
- 根据HTML规范，HTML开头必须注明
  - `<!DOCTYPE html>` 
- HTML使用标签(tag)标记各个内容,大部分标签是成对出现的，表示标记的范围
  - `<标签名>标签的范围</标签名>`
- vscode便捷操作，比如想要写一对标签，直接输入标签名，按回车键，就可以得到一对
- 标签名，有HTML官方规定的，也可以写自定义的，都不会报错

## HTML骨架

- 根据HTML规范，HTML必须要有如下结构
  - 在vscode中，顶行顶格打一个英文的`!` ,然后回车，就可以快速得到HTML骨架

```HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="description" content="全球最大的学习资料网站，48终身会员。">
    <meta http-equiv="refresh" content="5;url=http://www.baidu.com/">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    
</body>
</html>
```

- <!DOCTYPE html> 声明此文件为html格式
- <html lang="en"></html>  html标签表示HTML代码的部分，lang="en" 为此标签的属性
  - 标签的属性是key = "value" 格式
  - 标签有约定好的属性，也可以自定义
  - lang="en" 此页面的语言为英文，此属性是给浏览器看的
- <head></head> 此页面的头部，可以放一些页面的属性，比如此页面的关键字，此页面的文字编码，此页面的渲染处理等等，
- <meta> 不需要成对出现，使用属性声明一些内容
  - charset  文字编码，字符集
  - description  描述内容，主要给搜索引擎爬虫
  - http-equiv="refresh"  页面跳转
- <title></title>  页面的标题
- <body></body>  显示在页面中的内容

## table标签

```HTML
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>table标签示例</title>
</head>

<body>
    <center>
        <h1>table标签示例</h1>
    </center>
    <table border="1" cellspacing="0" align="center"><!-- 创建表格 -->
        <tr height="50px" align="center" bgcolor="pink" valign="middle"><!-- 创建行 -->
            <td width="50px"><!-- 创建列 -->
                序号
            </td>
            <td width="100px"><!-- 创建列 -->
                姓名
            </td>
            <td width="100px">
                性别
            </td>
            <td width="300px">
                爱好
            </td>
        </tr>
        <tr align="center">
            <td>1</td>
            <td>张三</td>
            <td colspan="2" bgcolor="purple">男</td>
        </tr>
        <tr align="center">
            <td>2</td>
            <td>李四</td>
            <td rowspan="2">男</td>
            <td>抽烟喝酒烫头</td>
        </tr>
        <tr align="center">
            <td>3</td>
            <td>王五</td>
            <td>睡觉</td>
        </tr>
    </table>

</body>

</html>
```

- table 创建一个表格
  - border 设置表格的边框宽度，默认是0
  - cellspacing  设置单元格之间的空隙，默认是1
  - align 设置表格在网页中的对其形式， left right center
- tr 只能写在table中，创建一行
  - height 调整行的高度
  - align   调整此行文字的对齐  left right center
  - bgcolor  调整背景色
  - valign  调整文字水平对齐  top middle bottom
- td 只能写在tr中，创建一列
  - width  调整宽度，一列中，只要调整一个就可以影响一整列
  - colspan  合并单元格，意思是此单元格需要占用两列的位置
  - rowspan 合并单元格，意思是此单元格需要占用两行的位置
  - bgcolor  修改单元格颜色

# CSS

- CSS是用来修饰和页面排版，不是编程语言
- CSS所有能用的属性：https://main.eagleslab.com/css3/
- CSS的应用方式
  - 行内样式，在标签中加入style
  - 内部样式，在head标签中，加入style
- 行内样式

```HTML
<a style="color: green;" href="https://www.baidu.com">点我呀</a>
```

- 内部样式
  - 在style中必须要加上选择器
    - 选择生效的标签
    - id选择器，`#xxx`
      - 在标签中有属性`id=xxx`
      - 建议id在整个页面是唯一的
    - class选择器，`.xxx`
      - 在标签中有属性`class="xxx"`
      - 多个标签可以使用同一个class
    - 标签选择器，`a`
      - 直接选择标签

```HTML
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS演示</title>
    <style>
        #effect {
            color: green;
            font-size: 32px;
            text-decoration: none;
            cursor: wait;
            text-shadow: 1px 1px 1px black;
            background-color: pink;
            border: 2px solid orange;
            padding: 20px;
            position: absolute;
            top: 20%;
            border-radius: 10px;
        }
    </style>
</head>

<body>
    <a id="effect" href="https://www.baidu.com">点我呀</a>
    <a href="#">不关我的事</a>
</body>

</html>
```

- 外部样式
  - index.css文件

```CSS
#effect {
    color: green;
    font-size: 32px;
    text-decoration: none;
    cursor: wait;
    text-shadow: 1px 1px 1px black;
    background-color: pink;
    border: 2px solid orange;
    padding: 20px;
    position: absolute;
    top: 20%;
    border-radius: 10px;
}
```

- 在index.html中可以引用外部的css文件

```HTML
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS演示</title>
    <link rel="stylesheet" href="index.css">
</head>

<body>
    <a id="effect" href="https://www.baidu.com">点我呀</a>
    <a href="#">不关我的事</a>
</body>

</html>
```

- 颜色代码
  - 在css中需要描述颜色的地方，可以使用颜色的英文单词，`green` `blue` `pink` ，但是颜色单词是不准确
  - 使用RGB可以精准的获取颜色，屏幕上面红绿蓝三种色彩亮度划分为0~255等级，使用rgb(红色，绿色，蓝色)可以描述，数字改为16进制，简写为`#aabbcc` 
  - 为了表示透明度，引入了alpha通道，也就是透明度，1是完全不透明，0是完全透明，表示为rgba(123,123,123,0.5)

## 常见的css样式

```CSS
color: green;            /* 设置字体颜色 */
font-size: 32px;        /* 设置字体大小 */
text-decoration: none;             /* 设置字体下划线为none */
cursor: wait;                    /* 设置光标的图案 */
text-shadow: 1px 1px 1px black;        /* 设置文字阴影，水平偏移 垂直偏移 模糊程度 阴影颜色 */
background-color: pink;                /* 设置元素背景颜色 */
border: 2px solid orange;            /* 设置元素边框，边框宽度 实线 边框颜色*/
padding: 20px;                    /* 设置元素到边框之间的距离 */
position: absolute;            /* 设置元素的定位方式 */
top: 20%;                        /* 设置元素离顶部20%的空间，相对于窗口 */
border-radius: 10px;            /* 设置元素边框角落的圆度 */
```

### 盒子模型

- 为了更好的服务于网页布局，css存在盒子模型概念，可以帮助调整每个元素之间的距离

![img](1.web开发/1753687083165-140.png)

- 最中间是元素本身
- padding 内边距，元素到边框之间的距离
- border  边框
- margin  外边距，元素之间的距离
- 大多数标签都有默认的盒子模型参数，在开发的时候，需要注意，或者全部去掉

![img](1.web开发/1753687083165-141.png)

- 将元素移动到网页正中间
  - position  给内容定位
    - static  默认，无定位
    - relative  相对定位，相对于父元素
    - absoulte  绝对定位，基于浏览器窗口
    - fixed  固定在窗口上，不会随着页面滚动而改变位置

    position: absolute;
    top: 50%;
    left: 50%;

## 登录实战

- 先写好html

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>欢迎登录</title>
</head>

<body>
    <form action="">
        <h1>欢迎登录</h1>
        <input type="text" placeholder="用户名">
        <input type="password" placeholder="密码">
        <input type="submit" value="登录">
    </form>

</body>

</html>
```

- input 获取用户的输入

  - type类型决定用户的输入形式
  - type="text"    单行文本框
  - type="password"    单行文本框，但是不显示输入内容
  - type="submit"    提交按钮

- form 定义提交的行为

  - action  提交到什么地方，如果什么都不写，默认提交到当前的url
