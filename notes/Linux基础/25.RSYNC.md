# 1. 什么是 rsync

## 1.1 rsync 简介

`rsync`（Remote Synchronization）是一款 **高效的文件同步和备份工具**，最初用于类 Unix 系统，现在也广泛用于 Linux 运维、服务器同步、备份恢复等场景。

> rsync 主要用于 **本地与远程之间** 或 **两台远程主机之间** 的高效文件同步。

------

## 1.2 rsync 的核心特点

✅ 支持 **增量同步**（只传输变化部分）

✅ 支持 **本地和远程同步**

✅ 支持通过 **SSH / rsh / socket** 传输

✅ 可保持 **权限、时间、软硬链接、属主属组**

✅ 支持 **限速、断点续传、删除目标多余文件**

✅ 无需特殊权限即可使用

------

## 1.3 rsync 的典型应用场景

- 服务器数据备份
- 文件镜像同步
- 日志、配置、数据库文件同步
- 跨主机批量分发文件
- 生产环境定时备份（cron + rsync）

------

# 2. rsync 原理

## 2.1 rsync 的核心思想

> **“只传输不同的部分，而不是整个文件”**

这是 rsync 与 `scp`、`cp`最大的区别。

------

## 2.2 为什么需要 rsync 算法？

假设我们有两个文件：

```
A 机器：fileSrc
B 机器：fileDst
```

如果直接 diff：

- 需要把文件完整传过去
- 失去“增量”意义

👉 所以 **不能 diff**

👉 必须：

- 两边文件**不见面**
- 但又要知道**哪些部分不同**

这就是 **rsync 算法** 要解决的核心问题。

------

## 2.3 rsync 同步基本流程

### ① 接收端（目标）

- 将目标文件 **分块**（如每块 512 字节）
- 对每一块计算两种校验值
  - **弱校验（rolling checksum）**
  - **强校验（md5 / sha）**

👉 生成 checksum 列表，发送给源端

------

### ② 发送端（源）

- 对源文件做同样的 **分块 + checksum**
- 使用 **rolling checksum + hash 表** 快速查找匹配块
- 若匹配：
  - 标记为“已存在”
- 若不匹配：
  - 标记为该块需要传输

------

## 2.4 checksum 的作用

| 校验类型         | 作用     | 特点           |
| ---------------- | -------- | -------------- |
| rolling checksum | 快速比较 | 快但碰撞概率高 |
| md5 checksum     | 精确确认 | 慢但安全       |

📌 **先用弱校验快速过滤，再用强校验确认**

------

## 2.5 rolling checksum 的意义

当文件中间插入一个字符：

```
123456789
↓
1x23456789
```

rsync 通过 **rolling（滑动窗口）** 方式：

```
[12345]
 [23456]
  [34567]
```

✅ 不需要重新分整个文件

✅ 只向后滑动 1 个字节

✅ 高效发现匹配块

------

## 2.6 最终传输内容

同步源端最终生成：

- ✅ **匹配块编号**（目标端已有）
- ❌ **真正需要传输的数据块**

👉 压缩后发送

👉 目标端重组文件

------

## 2.7 rsync 同步示意图（文字版）

```
源文件：  [A][B][不同1][C][D]
目标文件：[A][B][C][D]

传输内容：
- 不同1（真正的数据）
- 引用 A/B/C/D 的块编号
```

------

## 2.8 rsync 的优势总结

| 项目         | rsync    |
| ------------ | -------- |
| 是否增量     | ✅        |
| 是否高效     | ✅        |
| 是否支持远程 | ✅        |
| 是否安全     | ✅（SSH） |
| 是否适合生产 | ✅✅✅      |

# 3. 安装及相关应用

## 3.1 安装

```bash
[root@localhost ~]# yum -y install rsync
```

## 3.2 rsync命令格式

**格式**：

```bash
rsync options source destination
```

### 各部分含义

| 部分          | 含义                    |
| ------------- | ----------------------- |
| `rsync`       | 远程 + 本地文件同步命令 |
| `options`     | 同步方式、行为控制参数  |
| `source`      | 源文件或目录            |
| `destination` | 目标路径                |

📌 **source 和 destination 可以是：**

- 本地路径
- 远程主机（user@host:/path）

--------

**options 参数总表（集中版）**

### ✅ 常用核心参数（必须掌握）

| 参数 | 含义                   | 说明                                                         |
| ---- | ---------------------- | ------------------------------------------------------------ |
| `-a` | archive                | 归档模式（= `-rlptgoD`）,，允许递归拷贝数据的同时保存链接、文件权限、所有者用户和组还有时间戳 |
| `-v` | verbose                | 显示详细过程                                                 |
| `-r` | recursive              | 递归同步目录                                                 |
| `-l` | links                  | 保留软链接                                                   |
| `-p` | perms                  | 保留权限                                                     |
| `-t` | times                  | 保留修改时间                                                 |
| `-g` | group                  | 保留属组                                                     |
| `-o` | owner                  | 保留属主                                                     |
| `-D` | devices + specials     | 保留设备文件和特殊文件                                       |
| `-z` | compress               | 传输时压缩                                                   |
| `-h` | human-readable         | 人类可读格式                                                 |
| `-P` | `--progress --partial` | 显示进度 + 断点续传                                          |

------

### ✅ 增量 / 删除类参数（非常重要）

| 参数                | 含义                 | 说明                 |
| ------------------- | -------------------- | -------------------- |
| `-u`                | update               | 只同步更新的文件     |
| `--delete`          | 删除目标多余文件     | 保持**镜像同步**     |
| `--existing`        | 只同步已存在的文件   | 不新建               |
| `--ignore-existing` | 跳过目标已存在的文件 | 只同步新文件         |
| `--max-size=SIZE`   | 限制最大文件大小     | 如 `--max-size=100M` |

------

### ✅ 远程同步参数（生产环境必用）

| 参数                | 含义                 | 说明         |
| ------------------- | -------------------- | ------------ |
| `-e`                | specify remote shell | 指定远程协议 |
| `-e ssh`            | 使用 SSH             | 默认方式     |
| `-e "ssh -p 2222"`  | 指定 SSH 端口        | 非默认端口   |
| `--rsync-path=PATH` | 指定远程 rsync 路径  | 常用于 sudo  |

------

### ✅ 带宽 & 性能控制参数

| 参数              | 含义           | 说明               |
| ----------------- | -------------- | ------------------ |
| `--bwlimit=RATE`  | 限速           | 如 `--bwlimit=10M` |
| `--partial`       | 保留未完成文件 | 断点续传           |
| `--append`        | 追加方式同步   | 适用于大日志文件   |
| `--append-verify` | 追加 + 校验    | 更安全             |

------

### ✅ 输出 & 调试参数

| 参数         | 含义            | 说明                     |
| ------------ | --------------- | ------------------------ |
| `-n`         | dry run         | 模拟执行（**非常重要**） |
| `-i`         | itemize changes | 显示文件变化详情         |
| `-q`         | quiet           | 静默模式                 |
| `--stats`    | 显示统计信息    | 文件数、字节数           |
| `--progress` | 显示传输进度    | 大文件必备               |

------

### ✅ 特殊场景参数

| 参数                  | 含义               | 说明                 |
| --------------------- | ------------------ | -------------------- |
| `--exclude=PATTERN`   | 排除文件           | 如 `--exclude=*.log` |
| `--exclude-from=FILE` | 从文件读取排除规则 | 批量排除             |
| `--include=PATTERN`   | 强制包含           | 与 exclude 配合使用  |
| `--backup`            | 备份旧文件         |                      |
| `--backup-dir=DIR`    | 指定备份目录       |                      |
| `--sparse`            | 稀疏文件优化       | 大文件、虚拟机镜像   |
| `--hard-links`        | 保留硬链接         |                      |

## 3.3 rsync命令应用（复制/同步）

- 本机文件→本机

```bash

total size is 28.48K  speedup is 4.76
# -z压缩
# -v显示过程
# -h人类可读格式
```
