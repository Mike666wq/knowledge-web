# 2.Linux系统

Linux是一款开源、免费的操作系统内核，由林纳斯·托瓦兹于1991年创建。其核心特点是开放源代码、高度可定制、稳定安全，并支持多用户、多任务及多线程操作。基于Linux内核衍生出众多发行版（如Ubuntu、CentOS、Debian等），广泛应用于服务器、嵌入式设备、超级计算机及个人电脑领域。Linux遵循GNU通用公共许可证，鼓励全球开发者协作改进，形成了强大的开源生态，是互联网基础设施和云计算领域的重要基石。

Linux系统因为开源，任何人都可以得到源代码，并且按照自己的喜好去修改，并且再次发行。
