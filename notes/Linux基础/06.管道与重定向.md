# 1. I/O重定向

- I/O对应系统中的输入(input)和输出(output)

- 其中输入可以是键盘输入，鼠标输入等等。同样输出也可以输出到终端中或者文件中

- 对于Linux系统，我们常见的输入输出的类型有：

  - 标准输入 0

  - 标准正确输出 1

  - 标准错误输出 2

[![img-IO重定向](06.管道与重定向/IO重定向.png)](https://git.inmind-lab.com/aaronxu/Linux-book/src/branch/main/01.Linux基础/16.管道与重定向/IO重定向.png)

## 1.1 文件描述符(FD)

```bash
# 如果打开一个文件
[root@Gateway]:~$ vim out.txt

# 复制一个会话查看
[root@Gateway]:~$ ps aux |grep vim		# 查看vim的进程号
root        2303  0.6  0.2  11680  9088 pts/0    S+   14:48   0:00 vim out.txt
root        2305  0.0  0.0   3876  2048 pts/1    S+   14:48   0:00 grep --color=auto vim
[root@Gateway]:~$ cd /proc/2303/fd/		# 找到文件描述符的位置
[root@Gateway]:/proc/2303/fd$ ll
total 0
lrwx------. 1 root root 64 Jan 19 14:50 0 -> /dev/pts/0		# 标准输入，指向0号虚拟终端
lrwx------. 1 root root 64 Jan 19 14:50 1 -> /dev/pts/0		# 标准输出
lrwx------. 1 root root 64 Jan 19 14:50 2 -> /dev/pts/0		# 错误输出
lrwx------. 1 root root 64 Jan 19 14:50 3 -> /root/.out.txt.swp		# 文件描述符

```

| Number | Channel name | Description | Default connection | Usage        |
| ------ | ------------ | ----------- | ------------------ | ------------ |
| 0      | stdin        | 标准输入    | 键盘               | 只读         |
| 1      | stdout       | 标准输出    | 命令行             | 只写         |
| 2      | stderr       | 标准错误    | 命令行             | 只写         |
| 3+     | filename     | 其他文件    | none               | 读 and/or 写 |

## 1.2 输入输出重定向

- `>`：覆盖重定向

- `>>`：追加重定向

- `1>`：覆盖重定向正确的输出数据流

- `1>>`：追加重定向正确的输出数据流

- `2>`：覆盖重定向错误输出数据流

- `2>>`：追加重定向错误输出数据流

- `&>`：将标准输出和错误的输出都覆盖

- `&>>`：将标准输出和错误的输出都追加

- `<`：输入重定向，将文件的内容输入到对应的命令

- 特殊的重定向位置

```bash
[root@Gateway]:~$ echo "hello world" &> /dev/null		# 所有丢给null，相当于是一个巨大的垃圾桶

[root@Gateway]:~$ dd bs=512M count=4 < /dev/zero >file	# dd 用于文件对拷，不指定bs和count会将文件全部复制完
4+0 records in											# bs 一次写入的大小，不宜太大，因为会放在内存中，count 写入的次数
4+0 records out											# < dev/zero 从zero设备中获取文件，zeor设备可以获取到无线大的空数据
2147483648 bytes (2.1 GB, 2.0 GiB) copied, 24.3612 s, 88.2 MB/s
[root@Gateway]:~$ ll -h									# > file 输出重定向，写入到这个文件中
total 2.1G
-rw-r--r--. 1 root root    0 Jan 19 13:58 access.log
-rw-------. 1 root root  907 Jan 17 17:42 anaconda-ks.cfg
-rw-r--r--. 1 root root   44 Jan 19 13:52 at.jobs
-rw-r--r--. 1 root root 2.0G Jan 19 14:25 file
-rw-r--r--. 1 root root   16 Jan 19 13:48 snow.txt

```

# 2. 进程管道

- 管道符`|`可以将程序执行的结果传递给后续的程序

```bash
[root@Gateway]:~$ tree /etc | less		# tree执行的结果，less继续执行

[root@Gateway]:~$ cat /etc/passwd | grep "root"		# cat的内容输入到grep进行过滤
root:x:0:0:root:/root:/bin/bash
operator:x:11:0:operator:/root:/sbin/nologin

[root@Gateway]:~$ cat /etc/ssh/sshd_config | grep -Ev "^#|^$"	# 查看配置文件，但是不看注释和空行
Include /etc/ssh/sshd_config.d/*.conf
AuthorizedKeysFile	.ssh/authorized_keys
Subsystem	sftp	/usr/libexec/openssh/sftp-server

[root@Gateway]:~$ du -h . | tee raw_du.txt | sort -hr
2.1G	.
8.0K	./.ssh
0	./.config/procps
0	./.config
# du 是对当前的目录下的内容计算大小
# tee 将得到内容继续传递下去的同时记录一份到文件里面
# sort 排序
# 具体见： https://iproute.cn/html/linux/
```
